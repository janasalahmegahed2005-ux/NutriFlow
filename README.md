## 🔐 Authentication

- JWT-based authentication
- Passwords hashed with bcrypt
- Protected routes via Angular auth guard
- Role-based authorization (user / admin)

## 🍽️ Key Features

### Personalized Nutrition Targets
Calorie and macro targets are calculated using the **Mifflin-St Jeor formula** based on the user's weight, height, age, gender, and wellness goal.

### Food Search
Searches local MongoDB first, then falls back to **USDA FoodData Central** for comprehensive food data.

### Recipe Finder
Users enter ingredients they have and the app finds matching recipes sorted by match percentage — showing which ingredients they have ✅ and which they're missing ❌.

### Balance Score
A daily score from 0–100 based on calories, protein, carbs, fat, fiber, and water intake.
