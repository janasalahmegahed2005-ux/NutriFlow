# NutriFlow — Frontend (Angular + TypeScript)

NutriFlow is a personalized nutrition and wellness web application that helps users track their meals, understand their nutrition, monitor hydration and progress, discover recipes, and receive personalized nutrition insights.

The frontend is located in `frontend/` and is built with Angular and TypeScript. It communicates with the Node.js/Express backend over HTTP and never connects directly to MongoDB.

The backend is located in the project root.
